# FFXIV Mitigation Planner

A utility for planning mitigations in FFXIV encounters. Drag and drop abilities onto a timeline and get a visual representation of their durations and cooldowns -- no spreadsheets or doing timestamp math in your head. Save plans locally, or import/export them.

Currently work-in-progress; latest version deployed [here](http://ea-ffxiv-mitigation-planner.s3-website.us-east-2.amazonaws.com/) for preview! Original TODOs and future plans tracked [here](https://github.com/ayblodgett/MitigationPlanner/issues/1), current issues and plans can be found in this repo's Issues.
Initial fork can be found [here](https://github.com/ayblodgett/MitigationPlanner).
